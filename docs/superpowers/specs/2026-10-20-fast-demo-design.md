# 快速展示版设计

## 目标

在不触碰未完成业务闭环的前提下，将现有系统收敛为可快速展示的工程项目基础信息与数据导入界面。

## 导航范围

- 隐藏整个“驾驶舱”菜单分组。
- 数据中心仅显示“数据上传”和“批次管理”。
- 其余既有菜单与路由保持不变；被隐藏的数据中心页面不删除，以免影响已有链接和后续开发。

## 项目中心展示

项目列表卡片显示已有项目数据：项目名称、编号、项目性质、投资时序、项目状态、建设单位、实施周期、计划总投资与年度计划投资。

新建和编辑项目补齐对应的常用输入项。金额在前端以“万元”填写和显示，保存时转换为后端要求的“分”。

项目详情页沿用真实 API 数据，不引入模拟统计；补充显示已存在的分类、建设、投资与责任单位字段。

## 验收标准

1. 左侧不再出现“驾驶舱”。
2. 数据中心仅有“数据上传”“批次管理”两个可见菜单项。
3. 可创建项目并录入计划总投资、年度计划投资等展示字段。
4. 项目列表与详情可正确显示上述金额和分类字段。
5. 前端 TypeScript 检查通过。
